# Instagram Reels Uploader

Automated Python uploader for Instagram Reels using the Meta Graph API.

## Features

- Instagram Graph API v21.0
- Reel container creation
- Container status polling
- Automatic publication
- Five-minute maximum processing timeout
- Exponential network retry/backoff
- AWS S3 hosting
- Cloudinary hosting
- Automatic cleanup after successful publication
- CLI upload mode
- Directory-watch automation
- Structured Python logging
- Pydantic environment validation
